# Portfolio — potwierdzone ustalenia

Użytkownik potwierdził:
- Walbud/Walbud24: projekt dla klienta, wykonany od podstaw.
- Olaya — strona: projekt dla firmy powiązanej, wykonany od podstaw.
- Olaya — aplikacja: projekt dla firmy powiązanej, wykonany od podstaw.
- Można wykorzystać nazwy, logotypy i zatwierdzone zrzuty. Panel pokazujemy bez danych klientów i poufnych informacji.

Nie potwierdzono aktualnego statusu wdrożeń, ukończenia każdej funkcji ani rezultatów liczbowych. Zgoda na marki nie zastępuje weryfikacji opisów i poszczególnych materiałów.

## Dodanie szkiców lokalnie

Po git pull origin main oraz php artisan optimize:clear uruchom:
`php artisan kobcode:portfolio-drafts`

Komenda dodaje tylko brakujące rekordy według slugów i nie zmienia istniejących opisów ani publikacji. Szkice są nieopublikowane. Nie pobiera logotypów, nie robi zrzutów, nie dodaje fikcyjnych ekranów.

W panelu /admin uzupełnij problem, zakres, potwierdzone rozwiązanie i rezultat oraz status wdrożenia. Następnie dodaj zatwierdzony materiał, opis alternatywny i sprawdź opis przed publikacją.
