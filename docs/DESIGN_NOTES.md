# KOBCODE — studio experience

## Direction
Warm ivory, charcoal, cobalt accents, self-hosted Manrope typography, large project imagery, restrained motion. A decorative 3D object connects design and programming without pretending to be client work. Nationwide positioning, Radom only in company details. Olaya website and application lead; Walbud remains secondary.
